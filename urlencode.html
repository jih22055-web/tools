🔗 URL 编码解码

对网址、参数或中文进行 URL 编码（encodeURIComponent）与解码。

结果将显示在这里…

URL 编码解码工具，把网址、参数中的特殊字符转成 %XX 形式，或还原成可读文本。处理中文参数、空格、& 符号必备。

为什么要做 URL 编码

URL 里只允许特定字符，空格、中文、"&"、"="、"#" 等直接放进去会被浏览器或服务器误解。编码后它们变成 % 加两位十六进制，传输时才不会出错。

encodeURI 与 encodeURIComponent 的区别

前者保留 "/"、"?"、"=" 等分隔符，适合编码整个网址；后者连这些也编码，适合编码单个参数值。参数里含中文或特殊符号时，用后者才安全。

适用场景

  • 接口请求参数里有中文，先编码再拼接
  • 调试时把 %E4%B8%AD%E6%96%87 解码看原文
  • 生成带查询参数的分享链接
  • 排查参数里的 & 被截断的 bug

使用方法

  1. 选择编码或解码模式
  2. 填入完整网址或参数值
  3. 复制结果直接使用

常见问题

编码后中文变成一堆 %XX 正常吗？

正常。这是 UTF-8 字节的十六进制表示，服务端会自动解码还原。

为什么 "&" 编码后参数就不冲突了？

因为编码后的 %26 不再被当作参数分隔符，服务器会把它当成值的一部分。

解码后乱码怎么办？

可能是原字符串用了非 UTF-8 编码。本工具按 UTF-8 解码，多数现代网页和接口都用 UTF-8。
