💻 curl 转代码

把 curl 命令一键转成 fetch、axios、Python requests、Go、PHP 代码。

等待转换

支持 -X、-H、-d/--data/--data-raw/--data-binary、-u、-b。从浏览器 Network 面板「Copy as cURL」复制过来即可。

curl 转代码工具把浏览器 Network 面板复制出来的 curl 命令，直接翻译成可以直接跑的请求代码。调试接口时在浏览器里抓到一个请求，想搬到后端代码里重放，手抄 header 和 body 很容易出错，用这个一键生成就没有遗漏。

适用场景

  • 从浏览器「Copy as cURL」得到的请求，转成后端代码
  • 调第三方 API 时把文档里的 curl 示例转成项目语言
  • 抓包分析后快速复现请求
  • 学习不同语言发 HTTP 请求的写法差异

使用方法

  1. 把 curl 命令粘到输入框
  2. 选择目标语言（fetch / axios / Python / Go / PHP）
  3. 点「转换」
  4. 复制生成的代码，按需改动变量名

常见问题

支持哪些 curl 参数？

-X 方法、-H 请求头、-d/--data/--data-raw/--data-binary 请求体、-u 基础认证、-b Cookie、-A UA、-e Referer。其他参数会被忽略。

multipart 表单（-F）支持吗？

暂不支持。带文件的 -F 上传建议手写，或者用 Postman 生成代码。

生成的 Python 代码里 json= 和 data= 有什么区别？

请求体是合法 JSON 时用 json=payload（requests 会自动设置 Content-Type 并序列化），否则用 data= 原样发送。

Windows 下的 curl 命令带 ^ 转义怎么办？

先去掉 ^ 符号，或者从浏览器的 Copy as cURL (bash) 复制，那种格式能直接用。
