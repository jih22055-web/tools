二进制、八进制、十进制、十六进制之间的换算是计算机基础，也是编程和网络排查的高频操作。这个工具输入一个数，四种进制同时显示，支持负数和大整数。

计算机为什么用多种进制

人习惯十进制，但计算机底层用二进制（只有 0 和 1）。八进制和十六进制是二进制的缩写——3 位二进制对应 1 位八进制，4 位对应 1 位十六进制，写起来更短。程序员看内存地址、颜色值、权限位时天天和十六进制打交道。

IP 地址、颜色与进制

子网掩码、MAC 地址、IPv6、HTML 颜色值（#FF0000）本质都是进制的表示。掌握进制转换，这些概念就不再是天书。

常见问题

十六进制的 A-F 是什么意思？

十六进制有 16 个数字符号：0-9 之后用 A=10、B=11、C=12、D=13、E=14、F=15。所以 0xFF 就是十进制 255。

超过 2^53 的大整数准确吗？

JavaScript 的数字精度有限，超过 2^53 的大整数可能不准。本工具用原生 parseInt/toString，适合日常数值，超大整数需专门的大数库。

能转换小数吗？

本工具面向整数转换。小数在不同进制间的转换涉及精度问题，需要专门的算法。
