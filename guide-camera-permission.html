摄像头测试提示权限被拒绝怎么办

2026-11-25 · 约 643 字

点开摄像头测试，页面弹出授权框，手一快点成了"拒绝"；之后再打开就只剩一个黑屏，控制台报 NotAllowedError: Permission denied。这种情况基本都出在权限上，按下面四步排查，绝大多数能解决。

第一步：先看地址栏的安全状态

浏览器只在两种环境下允许调用摄像头：HTTPS 网站和 localhost（本机）。如果你的页面是 http:// 开头的普通网站，浏览器会直接拒绝，甚至不弹授权框。地址栏里如果没有小锁图标，先确认站点是否支持 HTTPS。

第二步：把被拒绝的权限改回来

一旦拒绝过，浏览器会记住这个选择，以后不再询问。要改回来：

  1. 点击地址栏左侧的图标（小锁或感叹号）
  2. 找到"摄像头"或"网站设置"一栏
  3. 把状态从"已阻止"改成"允许"
  4. 刷新页面，重新测试

Chrome 里也可以走设置 → 隐私和安全 → 网站设置 → 摄像头，在"不允许使用摄像头的网站"列表里把这个站点删掉。

第三步：检查系统层面的开关

浏览器有权限还不够，操作系统也可能挡着。Windows 用户打开 设置 → 隐私和安全性 → 摄像头，确认"摄像头访问"和"允许应用访问摄像头"两个总开关都是开的，并往下找到浏览器，保证它也在允许列表里。macOS 用户在 系统设置 → 隐私与安全性 → 摄像头 里做同样的检查。

第四步：设备是不是被别人占着

摄像头同一时间只能被一个程序独占。如果腾讯会议、钉钉、OBS 之类的软件正在用，浏览器就拿不到。关掉这些软件再试。另外注意有些笔记本有物理摄像头开关或键盘快捷键（比如 Fn + F8），误触之后指示灯都不亮，先按一下看看。

测试时注意的两件事

  • 别在浏览器控制台里直接调 API：某些浏览器要求用户有明确的点击动作才授予摄像头权限，控制台执行可能一律失败。
  • 外接摄像头要选对设备：如果有多个摄像头，测试页的下拉框里选对那个，默认的可能是不存在的虚拟设备。

一句话：先确认是 HTTPS，再到地址栏图标里把摄像头权限改成允许，然后查系统开关和占用程序。四步走完还不行，多半是设备本身的问题。
