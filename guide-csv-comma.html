CSV 转 Markdown 字段里有逗号怎么办

2026-11-25 · 约 616 字

一份 CSV 转 Markdown，结果表格列数错乱。原因往往是某个字段里带了逗号——比如地址"北京市朝阳区，建国路 1 号"，解析工具把它当成两列了。

CSV 用逗号分隔，但字段里也能有逗号

CSV 的规则里，含分隔符的字段必须用双引号包起来：

张三,"北京市朝阳区,建国路1号",13800138000

这样解析器看到引号，就知道里面的是一个完整字段，逗号不是分隔符。很多人手工写 CSV 时直接写 张三,北京市朝阳区,建国路1号,13800138000，那对不起，这就是四个字段。

字段里本身有双引号怎么办

规则是：把一个双引号写成两个双引号。比如字段内容 他说"你好"，在 CSV 里写作：

"他说""你好"""

外层一对引号表示这是带特殊字符的字段，里面每个真实的引号翻倍。解析时会把 "" 还原成一个 "。

为什么不能用 split(",") 解析

很多人图省事，读一行就 line.split(',')。这只在最简单的 CSV 上成立。一旦出现引号包住的逗号、引号内的换行、转义的双引号，split 就会把字段切碎。正确做法是用专门的 CSV 解析库（Python 的 csv 模块、JavaScript 的 Papa Parse 等），它们按状态机逐字符处理，能正确处理所有这些情况。

同理，自己拼 CSV 字符串也别用简单的 join(',')——每个字段都要判断是否需要加引号并转义内部引号。用库写出来最稳。

转 Markdown 时的特殊麻烦

Markdown 表格用竖线 | 分列。字段里如果有竖线（比如某些技术文档、代码片段），转 Markdown 时同样会把它当成列分隔符。规范做法是把字段里的竖线转义成 \|，或者用 HTML 实体 |。好的转换工具会自动处理这一步。

另外字段里的换行也要注意：Markdown 表格的一个单元格不能跨行，字段里的换行要替换成 <br> 或空格。

操作步骤

  1. 确认源 CSV 里含逗号的字段都正确加了双引号
  2. 用支持标准 CSV 解析的工具读入（不要用 split）
  3. 转换时让工具处理字段里的竖线和换行
  4. 生成后抽查几行，看列数是否一致

一句话：CSV 里带逗号的字段用双引号包起来，字段里的双引号写成两个。解析别用 split，转换 Markdown 时还要把字段里的竖线转义掉。
