🗺️ 地图坐标转换

WGS84、GCJ-02、BD-09 三种坐标系互转，解决地图点位偏移问题。

等待转换

GPS 设备给的是 WGS84，高德腾讯用 GCJ-02，百度用 BD-09。地图上位置偏移几百米，多半是坐标系没对上。

地图坐标转换解决中国特有的坐标系问题。GPS 设备输出的 WGS84 坐标直接放到高德地图上会偏几百米，因为国内地图用的是加密后的 GCJ-02（俗称火星坐标），百度又在此基础上再加密成 BD-09。拿到的坐标和地图对不上，八成就是没做转换。

适用场景

  • GPS 设备点位在高德地图上偏移几百米
  • 把百度坐标系的点位迁到高德或腾讯地图
  • 爬取的地图数据与 GPS 实际位置对不上
  • 开发地图功能时统一坐标系

使用方法

  1. 输入纬度和经度（逗号分隔）
  2. 选择原始坐标系
  3. 点「转换」
  4. 复制对应坐标系的经纬度

常见问题

为什么会偏移？

国家规定公开地图必须使用加密后的 GCJ-02 坐标，算法不公开。所以 WGS84 直接标注会在 GCJ-02 地图上偏移，通常几百米。

转换精度如何？

用的是业界通用的近似算法，误差通常在 1-2 米以内，日常使用足够。高精度测绘需求请用专业服务。

港澳台和境外怎么算？

境外坐标不做偏移，工具会自动判断范围，境外输入直接原样返回。

坐标顺序是纬度在前吗？

是的，本工具输入和输出都是「纬度, 经度」，和国内地图 API 的习惯一致。谷歌地图习惯是「纬度, 经度」但 URL 里常是「纬度,经度」。
