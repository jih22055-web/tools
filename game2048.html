🧩 2048 小游戏

经典 2048，方向键或手机滑动都行，带最高分记录和撤销一步。摸鱼五分钟刚好。

分数
0
最高分
0

电脑用 ↑↓←→ 或 WASD，手机上直接滑动。相同数字撞在一起会合并，目标 2048。

2048 的规则很简单：每次移动所有方块朝同一方向滑到底，两个相同数字相撞合并成它们的和，每步随机生成一个 2 或 4。四个方向都动不了就结束。最高分存在浏览器本地，清缓存会丢。

适用场景

  • 工作间隙摸两分钟鱼
  • 测一下自己还能不能合成 2048
  • 手机上随手玩，不用装 App
  • 跟朋友比最高分

使用方法

  1. 点「重新开始」开局
  2. 用方向键或滑动屏幕移动
  3. 数字相同的撞在一起会相加
  4. 走错了可以点「撤销一步」

常见问题

最高分会丢吗？

存在浏览器本地存储里，同一个浏览器同一个域名会一直在。清缓存、换浏览器、无痕模式都会丢。

为什么不能撤销多步？

只保留上一步，避免无限回退失去挑战性。

手机上玩不动？

确保在棋盘区域滑动，页面本身不会再滚动。如果滑动无效，试试点一下棋盘再滑。

最高能到多少？

理论最高是 131072，实际上能合出 2048 的人已经不多。
