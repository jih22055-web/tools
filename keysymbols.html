⌨️ 键盘符号速查

常用特殊符号大全：数学、箭头、货币、序号、希腊字母等，点击即复制。

点击任意符号直接复制到剪贴板。

键盘符号表把那些键盘上打不出来、又经常要用的符号集中起来。数学的 ± ≈ ≤、箭头 → ⇒、货币 € £ ₽、序号 ① ② ③、希腊字母 α β π，都是写文档、做表格、发消息时突然需要的。按分类找，或者直接搜名称，点一下就复制。

适用场景

  • 写文档需要插入特殊符号
  • 做表格时用序号或箭头增强可读性
  • 发消息想用打勾打叉、星星爱心
  • 写技术文档需要希腊字母和数学符号

使用方法

  1. 在搜索框输入分类名称（如「箭头」「货币」）
  2. 或者翻分类自己找
  3. 点击符号即复制到剪贴板
  4. 粘贴到需要的地方

常见问题

为什么有的符号显示成方框？

当前字体不含这个字形。换一种字体（如 Segoe UI Symbol、Noto Sans Symbols）通常能解决。

复制到 Excel 里会乱码吗？

Unicode 符号在 Excel 里一般正常。个别旧版 Excel 对 emoji 支持不好，纯符号没问题。

这些符号有快捷键吗？

Windows 可以按 Win + . 调出表情符号面板；macOS 按 Ctrl + Cmd + 空格调出字符检视器。

能一次复制多个吗？

当前是单个复制。需要组合多个符号建议逐个复制，或直接在文档里打出来。
