写正则表达式时最头疼的就是"到底能不能匹配上"。这个工具让你边写边测：输入正则和测试文本，匹配结果实时高亮显示，还能看到每个捕获分组的内容。

正则表达式是什么

正则（Regex）是一种描述字符串模式的语言，用来查找、替换、校验文本。比如 \d+ 匹配一个或多个数字，^[a-z]+$ 匹配纯小写字母。它强大但语法晦涩，几乎没人能一次写对，所以需要一个在线工具反复调试。

常用标志说明

g（global）全局匹配，找出所有结果而不是第一个；i（ignore case）忽略大小写；m（multiline）让 ^ 和 $ 匹配每一行的首尾；s（dotAll）让点号也能匹配换行符。灵活组合这些标志能满足大多数场景。

适用场景

  • 写表单校验规则（手机号、邮箱、身份证）前先验证
  • 从一大段日志里提取特定格式的内容
  • 批量替换文本前确认正则匹配范围
  • 学习正则时观察每个语法的效果

使用方法

  1. 在第一行输入正则表达式（不要写前后的 / 斜杠）
  2. 设置标志，常用 g 全局 + i 忽略大小写
  3. 在测试文本里粘贴内容，结果实时显示匹配数和位置

常见问题

为什么开启了 g 标志结果反而少了？

全局匹配下正则对象会记住上次的位置（lastIndex）。本工具每次输入都重新创建正则，不会有这个问题。

怎么写匹配中文的正则？

用 Unicode 范围 [\u4e00-\u9fa5] 匹配常用汉字，或在新版浏览器用 \p{Script=Han} 配合 u 标志。

正则里有特殊字符要转义吗？

要。像 . * + ? ( ) [ ] { } ^ $ | \ 这些是元字符，想匹配它们的字面值需要在前面加反斜杠转义。
