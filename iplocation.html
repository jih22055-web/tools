🌍 IP 归属地查询

查询 IP 地址的地理位置、运营商信息，支持查询本机公网 IP。

输入 IP 后点击查询

IP 归属地查询可以根据 IP 地址查到对应的国家、省份、城市和运营商信息。本工具调用公开的免费接口完成查询，支持 IPv4 地址。

适用场景

  • 排查异常登录来自哪个地区
  • 分析网站访问日志中的访客分布
  • 查询某个 IP 段的大致地理位置

使用方法

  1. 输入要查询的 IP 地址，或留空查询本机公网 IP
  2. 点击「查询」按钮
  3. 查看返回的地区、运营商等信息

常见问题

查询结果准确吗？

IP 地址库存在更新延迟，结果只能作为大致参考，不能作为精确定位依据。移动网络、VPN 等情况误差可能较大。

为什么查询失败？

免费接口有调用频率限制，或当前网络无法访问接口。稍后重试即可。
