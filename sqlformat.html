🗃️ SQL 格式化

一键美化 SQL 语句，关键字自动大写、按子句换行缩进，也可压缩成一行。

结果将在这里显示

支持 SELECT / INSERT / UPDATE / DELETE，自动大写关键字、按子句换行缩进，字符串与注释原样保留。

SQL 格式化工具可以把挤成一行的 SQL 语句重新排版：根据 SELECT、FROM、WHERE、GROUP BY、ORDER BY、JOIN 等子句自动换行缩进，同时把关键字统一成大写，字段列表按逗号拆行。读别人写的长 SQL、或者把日志里的单行 SQL 变回可读格式，用这个最省事。调试时经常需要把多行 SQL 压成一行复制到命令行，压缩功能就是干这个的。

适用场景

  • 读别人写的长 SQL，先格式化再分析逻辑
  • 排查线上问题时把日志里的单行 SQL 展开
  • 把多行 SQL 压成一行，方便贴到命令行或代码里
  • 代码评审前统一 SQL 书写风格

使用方法

  1. 把 SQL 粘贴到上方输入框
  2. 点「美化格式」自动换行缩进、大写关键字
  3. 需要单行版本就点「压缩成一行」
  4. 点「复制结果」拿走

常见问题

字符串里的关键字也会被大写吗？

不会。单引号、双引号包裹的内容和 -- 行注释、/* */ 块注释都会先被保护起来，格式化后再原样还原。

支持 MySQL 的 LIMIT 和 PostgreSQL 的 RETURNING 吗？

支持 LIMIT、OFFSET。RETURNING 等少数方言关键字不会被单独换行，但不会影响语句本身。

格式化会改变 SQL 的含义吗？

不会修改任何内容，只调整空白和大小写。但极端情况下（例如依赖空格分隔的字符串拼接）建议格式化后人工核对一次。

支持存储过程或 BEGIN...END 吗？

只做基础排版，复杂存储过程建议用专门的 IDE 格式化器。
