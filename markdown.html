📝 Markdown 预览

左边写 Markdown，右边实时预览渲染效果。支持标题、加粗、列表、链接、代码块、表格等常用语法。

写 Markdown 时想看看渲染出来是什么样？这个工具让你左边写、右边实时预览，支持标题、加粗斜体、列表、链接、代码块、引用等常用语法，写完直接复制。

Markdown 是什么

Markdown 是一种轻量级标记语言，用简单的符号（# 表示标题、** 表示加粗）就能排出漂亮的文档。GitHub、掘金、知乎、各类博客后台都支持它，是写技术文档和文章的主流方式。

为什么需要预览

Markdown 的符号规则需要记，写的时候很难确定最终效果。实时预览让你边写边看，发现格式不对立刻调整，避免发布后才发现排版乱了。

适用场景

  • 写 GitHub README 前预览排版效果
  • 发博客、论坛帖子前确认格式
  • 学习 Markdown 语法时即时看到每个符号的作用
  • 快速把 Markdown 转成可复制的内容

使用方法

  1. 在左侧输入或粘贴 Markdown 文本
  2. 右侧实时显示渲染后的效果
  3. 确认无误后复制使用

常见问题

支持表格吗？

基础语法支持标题、加粗、列表、链接、代码块、引用等。复杂语法（如表格、任务列表）各平台实现不同，本工具聚焦最常用的部分。

我写的内容会上传吗？

不会，渲染完全在浏览器本地进行，你的文字不会离开设备。

代码块里的特殊字符会被转义吗？

会。代码块内的 < > & 等会安全转义，不会当成 HTML 执行，预览是安全的。
