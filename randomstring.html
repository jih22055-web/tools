🎲 随机字符串生成

批量生成指定长度的随机字符串，可选字符集，使用加密级随机数。

点击生成

用浏览器加密级随机数（crypto.getRandomValues），不是 Math.random，可用于生成密钥、盐值、初始密码。

随机字符串生成器按你指定的长度和字符集吐出随机串。和随手敲键盘不同，它用的是浏览器的加密级随机数接口（crypto.getRandomValues），分布均匀、可预测性低，可以直接拿来当初始密码、API 密钥、盐值或者不重复的订单号。

适用场景

  • 批量生成初始密码发给新员工
  • 生成 API Key、Token、盐值
  • 造测试数据里的随机标识
  • 生成短链后缀、邀请码

使用方法

  1. 设置长度和生成数量
  2. 勾选需要的字符类型
  3. 建议保留「排除易混淆字符」，避免 0/O、1/l 看错
  4. 点「生成」，再点「复制全部」

常见问题

和 Math.random 有什么区别？

Math.random 是伪随机，可被预测，不能用于安全场景。crypto.getRandomValues 是密码学安全的随机源，生成密钥、密码必须用它。

为什么排除 0OoIl1？

这几个字符在不同字体下几乎一样，人工抄写或电话口述时极易出错。生成的密码要人念给别人的话，建议排除。

生成的长度有上限吗？

单次最长 512 字符，一次最多 100 条。够日常用，需要更大量可以调大数量分几次生成。

能保证不重复吗？

不保证。长度足够（16 位以上、字符集够大）时重复概率极低，但需要严格唯一请自行查重。
