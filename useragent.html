🔍 User-Agent 解析

解析 User-Agent 字符串，识别浏览器、版本、内核、系统与设备类型。

等待解析

识别浏览器、内核、操作系统、设备类型。用于看访问日志、排查兼容性问题。

User-Agent 解析工具把访问日志里那一长串浏览器标识拆开，告诉你这是什么浏览器、什么版本、跑在什么系统上、是手机还是电脑。做前端兼容性排查、分析访问来源、判断爬虫时都用得上——把日志里的 UA 粘进来就知道对面是什么。

适用场景

  • 分析 Nginx / Apache 访问日志里的访客设备
  • 排查「只有某个浏览器出问题」的兼容性 bug
  • 判断请求是真人还是爬虫
  • 产品调研时统计用户都用什么浏览器

使用方法

  1. 粘贴 User-Agent 到输入框
  2. 点「解析」
  3. 看浏览器、内核、系统、设备四项结果
  4. 不知道 UA 就点「填入我的浏览器 UA」

常见问题

为什么 Chrome 的 UA 里也有 Safari 字样？

历史遗留。Chrome 基于 WebKit 开发，为了兼容网站的各种 UA 判断，保留了 Safari 和 AppleWebKit 标记。所以识别时要先判断 Chrome 再判断 Safari，顺序错了就会认错。

UA 能完全信任吗？

不能。UA 是客户端自己发的，可以随意伪造。爬虫伪装成 Chrome 很常见，要配合 IP、行为特征综合判断。

iOS 上的 Chrome 会被识别成什么？

因为苹果限制，iOS 上所有浏览器都用 WebKit 内核，UA 里同时有 CriOS 和 Safari。本工具优先识别为 Chrome，但实际渲染引擎是 WebKit。

没有识别出来怎么办？

小众浏览器或新版本 UA 可能不在规则里。可以把 UA 发来补充规则，或者看里面的关键词自己判断。
