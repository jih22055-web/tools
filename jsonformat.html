📦 JSON 格式化

粘贴 JSON 后美化、压缩或校验，带语法高亮。

结果将显示在这里…

一键美化、压缩、校验 JSON 数据，带语法高亮和错误定位。接口返回一团乱麻时，粘贴进来立刻看清结构。

JSON 为什么需要格式化

接口返回的 JSON 常被压缩成一行，人眼很难读。格式化（pretty print）会加上缩进和换行，层级结构一目了然，是调试接口的第一步。

JSON 合法性的常见错误

多一个逗号、单引号代替双引号、注释、末尾多余内容——这些都会导致解析失败。本工具会明确指出错误位置，帮你快速定位。

适用场景

  • 调试 API，把返回的一行 JSON 美化后看字段
  • 提交前校验配置文件格式是否正确
  • 压缩 JSON 减小体积
  • 定位 JSON 里的语法错误

使用方法

  1. 把 JSON 粘贴到输入框
  2. 点「格式化」看缩进后的结构，或点「压缩」去空白
  3. 语法错误会在下方提示位置

常见问题

JSON 和 JavaScript 对象一样吗？

不一样。JSON 是严格的数据格式，键和字符串必须用双引号，不能有注释、不能有多余逗号，也不能是函数。

格式化会改变数据吗？

不会，只加空白和换行，数据内容和顺序完全不变。

大文件能处理吗？

几 MB 的 JSON 通常没问题，全部在本地浏览器处理，不上传服务器。
