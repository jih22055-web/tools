JSON 为什么需要格式化

接口返回的 JSON 常被压缩成一行，人眼很难读。格式化（pretty print）会加上缩进和换行，层级结构一目了然，是调试接口的第一步。

JSON 合法性的常见错误

多一个逗号、单引号代替双引号、注释、末尾多余内容——这些都会导致解析失败。本工具会明确指出错误位置，帮你快速定位。

常见问题

JSON 和 JavaScript 对象一样吗？

不一样。JSON 是严格的数据格式，键和字符串必须用双引号，不能有注释、不能有多余逗号，也不能是函数。

格式化会改变数据吗？

不会，只加空白和换行，数据内容和顺序完全不变。

大文件能处理吗？

几 MB 的 JSON 通常没问题，全部在本地浏览器处理，不上传服务器。
