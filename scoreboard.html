🏆 在线记分板

2 到 8 队同时计分，可改队名、一键加减、自动标出领先方，支持全屏投屏。

点队名可以改名。分数自动存在浏览器里，刷新不丢。全屏后适合投屏到电视或大屏。

记分板用在需要当场亮分的地方：家庭棋牌、单位趣味运动会、乒乓球擂台、课堂小组抢答、桌游计分。最多 8 队同屏，每队有 -5 / -1 / +1 / +5 四个按钮，领先的队伍会自动加粗描边标出来。分数存在浏览器里，手机放在桌上当记分牌，刷新页面也不会丢。全屏按钮适合投到电视上让所有人都看得见。

适用场景

  • 家庭扑克、麻将、桌游计分
  • 乒乓球、羽毛球、篮球打分局分
  • 公司团建、趣味运动会分队伍PK
  • 课堂小组抢答记分
  • 直播或线下比赛现场计分

使用方法

  1. 先在「队伍数量」里选几队
  2. 点队名可以改成自己人的名字
  3. 用 +1 / -1 / +5 / -5 加减分
  4. 要投到电视上就点「全屏」，结束后点「全部归零」

常见问题

分数会丢吗？

存在浏览器 localStorage 里，刷新、关掉再打开都还在。清缓存或换设备会清零。

能改加减的步长吗？

当前固定 -5/-1/+1/+5 四档，覆盖大部分棋牌和球类场景。

最多几支队伍？

8 支。再多屏幕会挤，建议分组。

手机上能用吗？

可以。手机竖屏会自动排成两列，横屏或投屏会排成更多列。
