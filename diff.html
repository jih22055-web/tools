📑 文本对比工具

并排或逐行对比两段文本，高亮显示新增、删除和相同的行。代码、文案改版对比的实用工具。

点「开始对比」查看差异…
🟢 绿色 = 新增　🔴 红色 = 删除　⚪ 灰色 = 未变

两段文字到底改了哪里？这个工具基于最长公共子序列算法逐行比对，新增、删除、未变的行用不同颜色标出，让差异一目了然。代码 review、文案改版、配置变更都能用。

文本对比解决什么问题

人眼对比两段相似的长文本非常容易看漏——尤其是只有几行改动时。diff 工具把相同部分折叠、差异部分高亮，让你把注意力全放在真正变化的地方。程序员提交代码前看 diff 就是同一个道理。

逐行对比的局限

本工具按行对比，适合代码、配置、清单这类结构化文本。如果只是一句话里改了几个字，逐行对比会显示整行不同——这种情况看颜色差异反而更清楚。

适用场景

  • 代码或配置改版前后对比，确认没有误改
  • 文案、合同的修订版本找出改动
  • 对比两份名单、数据的增减
  • 检查复制粘贴后内容是否有出入

使用方法

  1. 把原文贴进左侧，修改后的文本贴进右侧
  2. 点「开始对比」
  3. 绿色是新增，红色是删除，灰色是未变的行

常见问题

对比会上传我的文本吗？

不会，全部在浏览器本地用 JavaScript 计算，内容不会离开设备。

能对比中文吗？

可以，中文、英文、代码都支持，按行对比与语言无关。

顺序被打乱的行能识别吗？

逐行 diff 对顺序敏感，如果行顺序大量变动，会显示为大量删除+新增。这种情况建议先排序再对比。
