📄 XML 格式化

XML 美化缩进与压缩，自动校验标签闭合，错误定位到具体位置。

结果将在这里显示

基于浏览器原生 XML 解析器，能发现标签未闭合等语法错误。

XML 格式化工具把压缩成一行的 XML 按层级缩进展开，或者反过来把带大量缩进的 XML 压成一行。它使用浏览器原生 XML 解析器，所以不只是排版——标签没闭合、属性引号缺失这类语法错误会直接报出来，不用再靠肉眼找。

适用场景

  • 看接口返回的 XML 报文，先格式化再读结构
  • 排查 XML 配置文件的标签闭合错误
  • 把格式化后的 XML 压成一行嵌入请求体
  • 对比两份 XML 差异前先统一格式

使用方法

  1. 粘贴 XML 到输入框
  2. 点「美化缩进」查看层级结构
  3. 点「压缩」得到单行版本
  4. 有语法错误时会直接提示

常见问题

报语法错误但我看不出来？

常见原因：标签未闭合、属性值没加引号、& 没有转义成 &、XML 声明前面有多余空白。错误信息里会带上出错的行列位置。

支持 CDATA 吗？

支持，CDATA 段会原样保留。

中文会不会乱码？

页面是 UTF-8，正常输入中文没问题。如果源文件是 GBK 编码，先在编辑器里转成 UTF-8 再粘贴。

会保留注释吗？

美化模式会保留注释并缩进，压缩模式会去掉注释。
