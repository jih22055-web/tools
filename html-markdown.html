🔄 HTML 转 Markdown

粘贴 HTML 代码，一键转换成简洁的 Markdown 文本。

结果将在这里显示

HTML 转 Markdown 工具把网页代码转换成简洁的 Markdown 格式，保留标题、链接、列表、加粗、图片等常见元素，方便把网页内容迁移到文档系统或博客。

适用场景

  • 把网页文章转换成 Markdown 存到笔记里
  • 迁移旧网站内容到静态博客
  • 清理复制粘贴带来的冗余 HTML 标签

使用方法

  1. 粘贴 HTML 代码到输入框
  2. 点击「转换为 Markdown」
  3. 复制结果使用

常见问题

会保留样式吗？

Markdown 只描述内容结构，不保留 CSS 样式。转换会保留标题层级、链接、列表、加粗斜体、图片、代码块等语义元素。

表格和代码块能转换吗？

可以。常见的表格、行内代码、代码块都能正确转换，复杂嵌套结构可能被简化。
