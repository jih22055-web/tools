🔢 Base62 编码

Base62 编码与解码，把数字转成更短的字母数字字符串，常用于短链接和 ID。

结果将在这里显示

Base62 使用 0-9、a-z、A-Z 共 62 个字符表示数据，比十进制更紧凑。它常用于短链接、数据库主键压缩、分布式 ID 生成等场景。

适用场景

  • 生成短链接的短码
  • 把自增数字 ID 压缩成更短的字符串
  • 在 URL 中传递紧凑的标识符

使用方法

  1. 输入一个数字，点「编码」得到 Base62 字符串
  2. 粘贴 Base62 字符串，点「解码」还原数字
  3. 可批量处理，每行一个

常见问题

Base62 和 Base64 有什么区别？

Base62 只包含字母和数字，不含 + / = 等特殊符号，更适合放在 URL 里；Base64 包含 64 个字符，编码效率略高。

支持超大数字吗？

JavaScript 的安全整数上限是 2^53-1。更大的数字可能精度丢失，本工具按字符串模拟大数运算，可处理较长的数字。
