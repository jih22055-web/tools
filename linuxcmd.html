常见问题

这些命令在 macOS 上能用吗？

大部分能用，但 macOS 用的是 BSD 版本的工具，部分参数不同。例如 ls 的 -h、sed -i 的写法都有差异，需要时查 man 手册确认。

rm -rf 有多危险？

它会递归强制删除指定路径下的所有内容且不进回收站、无法恢复。执行前务必确认路径正确，尤其不要在根目录或变量为空时使用。

怎么知道一个命令有哪些参数？

用 man 命令名 查看完整手册，或命令加 --help 看简版说明。

为什么我的命令提示 command not found？

通常是没有安装对应的软件包，或者命令不在 PATH 环境变量里，可以用 which 命令名 确认。
