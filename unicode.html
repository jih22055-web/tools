㊰ Unicode 编码

中文与 Unicode 编码互转，支持 \u 格式、ASCII 转 Unicode、中文转 Unicode。

结果将在这里显示

Unicode 编码把字符表示成统一的标准格式，常见形式有 \u4e2d 和 中。本工具支持中文与 Unicode 编码互相转换，处理 JSON、JS 字符串中的转义字符时特别有用。

适用场景

  • 处理 JSON 或 JavaScript 中的 \u 转义字符
  • 把中文转成可在源码中安全存放的 Unicode 编码
  • 解码网页源码中的 &# 数字实体

使用方法

  1. 输入中文文本，点「转 Unicode」得到编码
  2. 输入 Unicode 编码，点「转中文」还原
  3. \uXXXX 格式用「\u 格式解码」按钮

常见问题

\u 和 &# 有什么区别？

\u4e2d 是 JavaScript、JSON 使用的转义格式；中 是 HTML 实体格式，用于网页中显示字符。两者表示同一个字符。

为什么转换后字符变多了？

一个中文字符用 Unicode 编码后通常变成 6 个字符（\u4e2d），这是正常的，编码本身就需要更多空间表示。
