🎨 CSS 美化与压缩

CSS 代码一键美化缩进或压缩成一行，显示压缩率，不破坏 calc 与 url。

结果将在这里显示

压缩时保留 calc() 与 url() 里的空格，不会破坏语法。

CSS 美化压缩工具处理样式表的两种极端需求：接手别人的压缩过的 CSS（全挤在一行）需要展开看结构；上线前又要把自己写的 CSS 压到最小体积。工具会先保护注释、字符串和 url() 里的内容，再做排版，所以 calc(100% - 20px) 这种带空格的表达式不会被压坏。

适用场景

  • 接手压缩过的第三方 CSS，展开看结构
  • 上线前压缩 CSS 减小体积
  • 检查自己写的样式有没有语法问题（大括号不匹配）
  • 把压缩后的 CSS 还原成可读格式做二次修改

使用方法

  1. 粘贴 CSS 到输入框
  2. 点「美化」得到缩进版本，或点「压缩」得到单行版本
  3. 压缩时会显示压缩率
  4. 点「复制」拿走

常见问题

压缩会破坏 calc() 吗？

不会。运算符号两侧的空格在压缩时保留，calc(100% - 20px) 依然有效。

为什么压缩后体积没小多少？

如果原文件本来就没什么空白和注释，压缩空间有限。真正减体积要靠 gzip/brotli，压缩只是第一步。

支持 SCSS / LESS 吗？

只处理标准 CSS 语法。嵌套写法（SCSS）会被当成普通选择器，需要先编译。

会去掉没用的样式吗？

不会。工具只做格式处理，不做无用代码分析（那需要结合 HTML 使用情况）。
