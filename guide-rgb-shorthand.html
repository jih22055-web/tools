#RGB 和 #RRGGBB 有什么区别

2026-11-25 · 约 482 字

看别人写的 CSS 里有 color: #f00，自己写的是 #ff0000，颜色一模一样。这两个是同一个颜色的两种写法：前者是简写，后者是完整写法。

展开规则：每位复制一次

#RRGGBB 用六位十六进制表示红、绿、蓝三个通道，每通道两位，取值 00 到 FF。#RGB 把每个通道压缩成一位，展开时把这一位重复两次：

  • #ABC → #AABBCC
  • #f00 → #ff0000（纯红）
  • #fff → #ffffff（纯白）
  • #369 → #336699

最常犯的错是以为 #ABC 等于 #A0B0C0——那是"后面补零"，不是"重复一次"。正确结果是 #AABBCC，颜色明显更亮。

什么时候能简写

不是所有颜色都能压成三位。只有当每个通道的两位完全相同（比如 AA、FF、33）时才能简写。#FF8800 里 88 可以缩写但 00 也行，它能写成 #F80；而 #FF8040 的绿色通道是 80、蓝色是 40，两位不一样，就没法简写。

换句话说，理论上 1600 多万种颜色里只有 4096 种能简写。设计稿里给出的颜色大多是六位，正是因为它们通常不在那 4096 种里。

带透明度的情况

现代 CSS 还支持八位写法 #RRGGBBAA，最后两位是 alpha 通道（00 全透明，FF 完全不透明）。对应的简写是四位 #RGBA，同样每位重复一次：#F008 等于 #FF000088，也就是半透明红色。

该用哪种

  • 团队协作和代码可维护性优先 → 统一用六位，直观、不用在脑子里展开
  • 手写小段样式、追求简洁 → 能用三位就用三位，比如 #000、#fff、#333
  • 需要透明度 → 用八位 #RRGGBBAA，比 rgba() 更短

还有一点值得注意：早期 IE 不支持三位简写，但那已经是二十年前的问题了，现在所有浏览器都支持。真正需要留意的是某些老旧的邮件客户端，写邮件模板时最好用六位。

一句话：#ABC 就是 #AABBCC，每位重复一次而非补零。只有每通道两位相同时才能简写，拿不准就用六位最保险。
