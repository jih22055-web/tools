Base64 → 图片

图片转 Base64 工具可以把图片转换成 Base64 编码字符串，直接嵌入 HTML 或 CSS 里，省掉一次图片请求。也可以把 Base64 字符串还原成图片预览，适合处理邮件模板、单文件页面、富文本编辑器里的图片。

适用场景

  • 做单文件 HTML 页面，把图标内嵌进去
  • 邮件模板里配图，避免被邮箱屏蔽外链
  • 给富文本编辑器插入图片数据
  • 把 Base64 图片还原出来查看

使用方法

  1. 拖入图片，页面会显示预览和大小对比
  2. 按需要点「复制纯 Base64」「复制 Data URI」「复制 img 标签」或「复制 CSS 背景」
  3. 反向操作时把 Base64 粘贴到下方文本框，点「预览图片」
  4. 注意 Base64 会让体积增加约 33%，大图不建议内嵌

常见问题

Base64 为什么会让体积变大？

Base64 用 64 个可打印字符表示二进制数据，每 3 个字节编码成 4 个字符，所以体积会增大约三分之一。图片越大浪费越多。

多大的图片适合转 Base64？

一般建议 10 KB 以内的小图标、logo。超过 30 KB 就不划算了，正常的图片请求更快，而且能利用浏览器缓存。

为什么复制到 HTML 里图片显示不出来？

检查是否复制了完整内容，Data URI 必须以 data:image/... 开头。另外部分邮箱和富文本编辑器会过滤掉 Data URI 图片。

转换会上传图片吗？

不会。全部在浏览器本地用 FileReader 读取转换，图片不会发送到服务器。
