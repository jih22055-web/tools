📐 HTML 美化与压缩

HTML 代码美化缩进或压缩，script/style/pre 内容原样保护。

结果将在这里显示

script、style、pre、textarea 内部内容不会被改动，避免破坏代码。

HTML 美化压缩工具把一长串 HTML 按标签层级重新缩进，或者反过来去掉所有多余空白压成一行。关键在于保护 script、style、pre、textarea 这四个标签的内部内容——浏览器对它们里面的空白敏感，随便压缩会把 JavaScript 代码或预格式化文本搞坏，工具会先把这些整段摘出来，排版完再放回去。

适用场景

  • 看别人的 HTML 源码，先格式化理清层级
  • 发布前压缩 HTML 减少体积
  • 检查标签嵌套有没有写错（缩进错乱通常意味着标签不配对）
  • 把压缩过的 HTML 还原成可读格式

使用方法

  1. 粘贴 HTML 到输入框
  2. 点「美化缩进」看层级结构
  3. 或点「压缩」得到单行版本并显示压缩率
  4. 点「复制」拿走

常见问题

为什么 script 里的代码没被压缩？

故意保留的。压缩 JS 代码需要专门的语法分析，简单去空白可能破坏字符串和正则表达式，所以整段原样保留。

inline 元素换行会不会影响显示？

美化只在标签之间加换行和缩进，浏览器渲染 HTML 时标签间空白通常折叠成一个空格，极少数依赖精确空白的场景（如 inline-block 排版）需要人工检查。

支持 JSX / Vue 模板吗？

只按标准 HTML 标签规则处理。JSX 的自闭合写法和 Vue 的指令不会被特殊处理，但通常也不会出错。

表格压缩后还能正常显示吗？

能。table/tr/td 之间的空白对渲染没有影响。
