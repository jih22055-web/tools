📊 CSV 转 Markdown

把 CSV 数据转换成 Markdown 表格，支持多种分隔符，可直接复制粘贴。

结果将在这里显示

CSV 是常见的数据交换格式，Markdown 表格适合写在文档和 README 中。本工具把 CSV 快速转换成 Markdown 表格，支持自定义分隔符和是否包含表头。

适用场景

  • 把 Excel 导出的数据贴到 Markdown 文档
  • 生成 GitHub README 中的表格
  • 整理爬虫或数据库导出的数据

使用方法

  1. 粘贴 CSV 内容到输入框
  2. 选择分隔符和是否首行为表头
  3. 点击「转换」得到 Markdown 表格

常见问题

字段里有逗号怎么办？

标准 CSV 用双引号包裹含逗号的字段，如 "北京,中国"。本工具支持这种引号包裹的写法。

转换后表格对不齐？

Markdown 表格不要求列宽对齐，渲染引擎会自动处理。复制后直接粘贴到支持 Markdown 的编辑器即可。
