🧾 YAML 与 JSON 互转

YAML 与 JSON 双向转换，支持嵌套结构与数组，语法错误带行号提示。

结果将在这里显示

写 Docker Compose、K8s 配置时互相转换很方便。YAML 语法错误会提示具体行号。

YAML 转换工具负责在 YAML 和 JSON 之间互转。YAML 靠缩进表达层级，写配置文件很舒服但不好程序处理；JSON 结构清晰但写起来啰嗦。这个工具两边都能转：把 YAML 配置转成 JSON 看完整结构，或者把接口返回的 JSON 转成 YAML 塞进配置文件。

适用场景

  • 把 Docker Compose、K8s 的 YAML 转成 JSON 便于程序读取
  • 把接口返回的 JSON 转成 YAML 写进配置
  • 检查 YAML 缩进是否写错（语法错误会提示行号）
  • 给不熟悉 YAML 的同事看结构时转成 JSON

使用方法

  1. 把 YAML 或 JSON 粘贴到输入框
  2. 点「YAML 转 JSON」或「JSON 转 YAML」
  3. 结果里检查结构是否符合预期
  4. 点「复制」拿走

常见问题

为什么不支持 YAML 的多文档（--- 分隔）？

当前只解析第一个文档。多文档场景建议拆开分别转换。

锚点、别名（&a / *a）会展开吗？

会展开成实际内容，转换后不再保留锚点定义。

YAML 里的日期会被转成什么？

会被 JavaScript 解析成日期对象，输出成 ISO 格式的字符串（如 2026-11-23T00:00:00.000Z）。

缩进用几个空格？

输出统一用 2 空格，这是社区最常见的约定。
