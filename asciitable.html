🔣 ASCII 码表速查

完整 ASCII 码表 0-127，十进制/十六进制/二进制/字符对照，可搜索可复制。

点击任意一行复制对应字符。

ASCII 码表把 0 到 127 每个编码对应的字符、二进制、十六进制一次列全。写程序时遇到乱码、协议里看到 0x0D 0x0A 不知道是什么、需要确认某个字符的编码值，查这张表最快。表格支持按字符或编码搜索，点击任意一行直接复制字符。

适用场景

  • 排查乱码问题时对照编码值
  • 确认换行符到底是 LF(10) 还是 CRLF(13+10)
  • 协议分析时查控制字符含义
  • 学习字符编码基础

使用方法

  1. 直接在搜索框输入字符、十进制数或 0x 十六进制
  2. 或用下方按钮筛选控制字符 / 可打印字符
  3. 点击表格任意一行复制该字符

常见问题

ASCII 只有 128 个字符吗？

标准 ASCII 是 0-127 共 128 个。128-255 是扩展 ASCII（Latin-1），不同地区编码表不同，没有统一标准。

中文在哪里？

ASCII 里没有中文。中文在 GBK、UTF-8 等多字节编码里，占多个字节，不属于 ASCII 范畴。

换行符 LF 和 CRLF 的区别？

LF 是 10（0x0A），Unix/Linux/macOS 用。CRLF 是 13+10（0x0D 0x0A），Windows 用。跨平台处理文件时经常要转换。

为什么有的控制字符显示不出来？

0-31 和 127 是不可打印字符，屏幕上没有字形。表格里用说明文字标注它们的含义。
