🧮 子网掩码计算

根据 IP 与掩码位数计算网络地址、广播地址、可用主机范围。

子网掩码用于划分 IP 网络，决定一个网段的网络地址和可用主机范围。输入 IP 地址和掩码位数（CIDR），即可算出网络地址、广播地址、可用 IP 数量等信息。

适用场景

  • 规划局域网网段，判断两个 IP 是否在同一子网
  • 配置路由器、防火墙的网段规则
  • 学习 CIDR 与子网划分

使用方法

  1. 输入一个 IP 地址
  2. 输入掩码位数（如 24 表示 255.255.255.0）
  3. 点击「计算」查看结果

常见问题

掩码位数是什么意思？

CIDR 表示法，如 /24 表示前 24 位是网络位，对应子网掩码 255.255.255.0。位数越小，网段越大。

可用主机数怎么算？

可用主机数 = 2^(32-掩码位数) - 2，减去的两个地址分别是网络地址和广播地址。/24 网段有 254 个可用 IP。
