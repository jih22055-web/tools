🔗 URL 参数解析

解析 URL 里的查询参数，自动解码，可编辑后重新生成完整链接。

等待解析

自动 URL 解码，重复参数会分别列出。做接口调试、看别人链接里带了什么参数很方便。

URL 参数解析工具把链接问号后面那一串 a=1&b=2&c=3 拆成表格，自动做 URL 解码，中文参数也能直接看懂。调试接口时想改某个参数重发请求、看别人分享的链接里带了哪些追踪参数、从长链接里提取关键信息，用它比肉眼数 & 快得多。

适用场景

  • 分析分享链接里的追踪参数（utm_source 之类）
  • 调试接口时修改查询参数
  • 从长 URL 里提取有用字段
  • 检查参数是否正确编码

使用方法

  1. 把 URL 粘到输入框
  2. 点「解析参数」看表格
  3. 直接编辑参数名或值，点「重新生成」得到新链接
  4. 或点「复制」拿走原链接

常见问题

中文参数为什么显示成 %E5%B7%A5 这样？

URL 里的非 ASCII 字符必须编码。工具会自动解码显示成中文，重新生成时再编码回去，所以复制的链接依然可用。

重复的参数名怎么处理？

会分行列出，比如 tags=a&tags=b 显示两行，重新生成时也会保留两个。

锚点（# 后面）会参与解析吗？

不参与。锚点部分单独显示，查询参数只解析 ? 到 # 之间的内容。

能解析 POST 请求的 body 吗？

不能，本工具只处理 URL。表单 body 可以用 URL 编码解码工具处理。
