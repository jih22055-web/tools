前端开发、UI 设计时经常要在 HEX、RGB、HSL 之间换算颜色。这个工具带取色器，选色或输入任意一种格式，其余格式实时算出，并给出可直接复制的 CSS 代码。

三种颜色格式的区别

HEX（如 #5B8CFF）是网页设计最常用，本质是 RGB 的十六进制写法；RGB 用三个 0-255 的数字表示红绿蓝；HSL 用色相、饱和度、亮度描述颜色，更符合人对色彩的直觉——想让某个颜色变浅，直接调亮度百分比即可。

什么时候用哪种

写 CSS 时 HEX 最简洁；做颜色渐变、透明度动画时 rgba() 更方便；需要批量调整一系列颜色的深浅、明暗时，HSL 最直观，只改一个亮度值就能生成同色系。

适用场景

  • 从设计稿取色后转成 CSS 代码
  • 把 RGB 值换算成 HEX 填进样式表
  • 基于一个主色调生成同色系的浅色/深色
  • 确认文字与背景色的对比度是否够

使用方法

  1. 用取色器选颜色，或直接在输入框填 HEX 值
  2. 下方即时显示 RGB 和 HSL 结果
  3. 复制底部的 CSS 代码用到项目里

常见问题

#RGB 和 #RRGGBB 有什么区别？

三位的 #RGB 是六位的简写，每位重复一次，比如 #abc 等于 #aabbcc。本工具两种都支持。

HSL 的色相是什么意思？

色相是颜色的"种类"，用 0-360 度的角度表示：0 是红、120 是绿、240 是蓝。饱和度是鲜艳程度，亮度是明暗程度。

取色器只能选 HEX 吗？

取色器输出的是 HEX，但本工具会同时换算成 RGB、HSL 和 CSS 代码，你想要哪种复制哪种。
