💻 假装系统在升级

一键全屏模拟系统更新界面，带进度条和「卡在 99%」效果，ESC 退出。

生成一个全屏的「系统正在更新」界面，用于演示、拍视频、或者单纯不想被人打扰。
按 ESC 或点右下角小按钮可随时退出。

纯前端模拟，不动你系统里的任何东西。全屏后按 ESC 退出，如果是真全屏需要再按一次 ESC。

这个工具纯粹是玩：把屏幕变成一个正在安装更新的界面，用来拍视频、做演示、或者单纯让路过的人以为这台电脑在忙。提供四种风格——经典的 Windows 蓝底更新、macOS 浅色升级、深色极简、系统维护。进度条会随机加速和停顿，最后故意卡在 99% 不动，这是真更新最真实的细节。按 ESC 立刻退出，不会动你系统里的任何东西。

适用场景

  • 拍短视频需要一个「电脑在更新」的场景
  • 演示时需要模拟系统维护界面
  • 不想被打扰时让屏幕显示成在忙
  • 逗同事说电脑在装系统

使用方法

  1. 选风格、改标题、调进度上限
  2. 点「进入全屏演示」
  3. 画面会全屏接管，进度条自动走
  4. 按 ESC 退出（真全屏需要再按一次）

常见问题

会真的改我的系统吗？

不会。这是一个网页，只在浏览器里画界面，不碰系统设置、不改注册表、不装任何东西。

为什么进度卡在 99% 不动？

故意的。真实更新经常卡在最后一步很久，这个细节让它看起来更像真的。可以在设置里改「卡多久」。

能自定义文字吗？

可以，主标题输入框里改，支持中文英文。

全屏退不出来怎么办？

按 ESC。如果浏览器进入了真全屏，再按一次 ESC 或 F11 退出全屏。
