HTML 特殊字符表收录了网页开发中最常用的实体字符，包括转义字符、货币符号、数学符号、箭头、标点和常用图标，每条都列出命名实体、十进制与十六进制三种写法，点击即可复制。

适用场景

  • 写 HTML 时不知道 < 和 & 该怎么转义
  • 找箭头的实体编码
  • 给页面加对勾、星星等符号又不想用图片
  • 核对某个符号的 Unicode 码点

使用方法

  1. 在搜索框输入符号本身或中文名称，例如「版权」「箭头」
  2. 表格里查看三种写法：命名实体、&#十进制;、&#x十六进制;
  3. 点击任意一行即可把该字符复制到剪贴板
  4. 按需选择写法：命名实体可读性好，数字实体兼容性更广

常见问题

命名实体和数字实体有什么区别？

命名实体如 &copy; 可读性好，但不是所有符号都有命名；数字实体如 &#169; 任何字符都能表示，兼容性最广。HTML5 支持绝大多数命名实体。

什么时候必须转义？

在 HTML 里直接出现 <、>、& 会被当成标签或实体开头，必须转义。写在 script 或 style 里的内容另有规则，不能简单套用。

为什么有的字符显示成方块？

说明当前字体缺少该字符的字形。可以换用支持更全的字体，或者直接用图标库替代。

&nbsp; 有什么坑？

它是不换行空格，宽度固定，过多使用会导致对齐混乱，也不利于屏幕阅读器。排版间距建议用 CSS 的 margin 或 padding。
