📝 在线临时笔记本

免登录打开即写，多篇分标签，自动保存，可一键下载 txt。

0 字已自动保存

⚠️ 内容存在浏览器 localStorage 里：换设备、换浏览器、清缓存都会丢。重要内容请点「下载 txt」存到本地。

有时候只想记一段话：网址、会议要点、突然想到的句子，开 Word 太重，开记事本又找不到。这个临时笔记本打开就能写，每停 0.4 秒自动保存，关掉浏览器再打开内容还在。可以开多篇分标签，写完点「下载 txt」存到本地。它的定位就是「临时」，所以没有云同步——重要内容一定要下载下来。

适用场景

  • 临时记一段话、一个网址、一个灵感
  • 开会时快速记要点
  • 复制粘贴中转站
  • 写完一段文案先放一放，回头再改

使用方法

  1. 打开就直接在文本框里写
  2. 要分多篇点「新建笔记」，标签会在上方排开
  3. 改完不用点保存，停顿一下就自动存
  4. 需要带走点「下载 txt」，内容会存成文件

常见问题

关掉浏览器内容还在吗？

在。存在 localStorage 里，同一台电脑同一个浏览器再打开就还在。

换手机能看到吗？

不能。纯本地存储，没有账号也没有云同步。

清浏览器缓存会丢吗？

会。这是 localStorage 的固有限制，重要内容请下载 txt。

有没有字数上限？

浏览器 localStorage 单域名一般约 5MB，纯文字大概能存上百万字，日常够用。
