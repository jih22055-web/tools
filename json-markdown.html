📋 JSON 转 Markdown

把 JSON 数据转换成 Markdown 表格或列表结构，方便写文档。

结果将在这里显示

把 JSON 数据快速转换成 Markdown 表格或缩进列表，方便写接口文档、配置说明和数据字典。对象数组会转成表格，嵌套结构会转成列表。

适用场景

  • 把接口返回的 JSON 示例写进文档
  • 生成配置参数说明表格
  • 整理数据字典

使用方法

  1. 粘贴 JSON 内容
  2. 点「转表格」得到 Markdown 表格，或点「转列表」得到层级列表
  3. 复制结果粘贴到文档中

常见问题

支持嵌套 JSON 吗？

转列表模式支持嵌套对象，会用缩进展示层级；转表格模式只展开第一层的字段，嵌套值会以 JSON 字符串显示。

JSON 格式错误怎么办？

工具会提示解析失败。请检查引号、逗号是否完整，可用 JSON 格式化工具先校验。
