🔐 Htpasswd 密码生成

在线生成 Apache .htpasswd 密码行，支持 SHA-1 与明文格式。

等待生成

把生成的一行追加进 .htpasswd 文件即可。Apache 直接支持 {SHA} 格式；Nginx 需要 bcrypt 格式，请用 htpasswd -B 命令生成。

Htpasswd 生成器帮你造出 Apache 基本认证需要的密码行。格式是「用户名:加密后的密码」，每行一个用户，放进 .htpasswd 文件再配合 .htaccess 就能给目录加个账号密码。手工算哈希很麻烦，用这个填好用户名密码直接复制。

适用场景

  • 给网站目录加简单的账号密码保护
  • 给后台管理页面（如 phpMyAdmin）加一层认证
  • 搭建测试环境时快速造几个测试账号
  • 临时限制某个路径的访问权限

使用方法

  1. 填写用户名和密码
  2. 选择加密格式
  3. 点「生成」
  4. 把结果整行追加到 .htpasswd 文件

常见问题

为什么只有 SHA-1 和明文？

bcrypt 和 APR1-MD5 需要专门的实现库，纯前端跑不动。SHA-1 格式 Apache 完整支持，是纯前端能做的最实用格式。

Nginx 能用这个吗？

不能。Nginx 的 auth_basic 只支持 crypt、apr1、bcrypt 格式。在服务器上执行 htpasswd -B -c .htpasswd 用户名 生成 bcrypt 格式。

.htaccess 怎么配？

在需要保护的目录放 .htaccess，写入：AuthType Basic、AuthName "Restricted"、AuthUserFile /绝对路径/.htpasswd、Require valid-user。

SHA-1 还安全吗？

SHA-1 已被证明存在碰撞攻击，不适合做数字签名。但用作密码存储（加盐场景）风险低于碰撞攻击，作为基础认证够用。高安全要求请用 bcrypt。
